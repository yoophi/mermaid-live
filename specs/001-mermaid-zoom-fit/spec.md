# Feature Specification: Mermaid Zoom Fit

**Created**: 2026-07-07  
**Status**: Draft  
**Input**: User description: "프로젝트(AW)에서는 agent-run 패널 내 mermaid chart 를 전체 화면 모달에 적정하게 표시하기 위한 수정이 반영되어 있습니다. mermaid chart 를 화면에 표시할 때 AW 에서 전체 화면 모달에 zoom to fit 방식으로 표시하는 방식을 적용하여 화면 표시를 개선해주세요. 표시 방식은 현재 방식으로 유지(모달로 전환하는 것이 아니라 현재 방식 유지)하되 화면에 표시될 때 가장 적당한 크기로 자동으로 렌더링될 수 있도록 합니다"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 차트가 처음부터 적정 크기로 보임 (Priority: P1)

사용자는 Mermaid 차트가 포함된 화면을 열었을 때, 차트 전체가 현재 표시 영역 안에서 잘리지 않고 한눈에 보이기를 원한다.

**Why this priority**: 이 기능의 핵심 가치이며, 사용자가 차트 구조를 확인하기 위해 즉시 스크롤하거나 수동으로 배율을 조정해야 하는 문제를 줄인다.

**Independent Test**: 크기가 서로 다른 Mermaid 차트를 화면에 표시하고, 최초 표시 시 차트 전체가 현재 표시 영역 안에 들어오며 텍스트를 읽을 수 있는지 확인한다.

**Acceptance Scenarios**:

1. **Given** Mermaid 차트를 표시할 수 있는 화면이 열려 있고 차트 데이터가 준비되어 있음, **When** 사용자가 차트 표시 영역을 확인함, **Then** 차트는 표시 영역 안에 잘리지 않고 자동으로 맞춰진 크기로 보인다.
2. **Given** 차트가 표시 영역보다 큰 폭이나 높이를 가짐, **When** 차트가 렌더링됨, **Then** 차트 전체가 보이도록 축소되어 표시된다.
3. **Given** 차트가 표시 영역보다 작음, **When** 차트가 렌더링됨, **Then** 차트는 과도하게 작아지지 않고 읽기 쉬운 크기로 표시된다.

---

### User Story 2 - 현재 표시 방식이 유지됨 (Priority: P2)

사용자는 기존 화면 흐름을 유지한 상태에서 차트 크기만 더 적절하게 조정되기를 원한다.

**Why this priority**: 요청 범위가 표시 품질 개선에 한정되어 있으므로, 차트를 새로운 전체 화면 모달로 전환하는 등 사용 흐름을 바꾸면 기대와 다를 수 있다.

**Independent Test**: 기존에 차트가 표시되던 화면과 진입 방식을 사용해 차트를 열고, 차트가 별도 전체 화면 모달로 전환되지 않는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 기존 방식으로 Mermaid 차트를 표시하는 화면이 있음, **When** 사용자가 차트를 표시함, **Then** 차트는 기존 화면 내 표시 위치와 흐름을 유지한다.
2. **Given** 차트 표시 개선이 적용됨, **When** 사용자가 차트를 확인함, **Then** 사용자는 새로운 모달 전환이나 별도 화면 이동 없이 개선된 크기의 차트를 볼 수 있다.

---

### User Story 3 - 표시 영역 변화에 맞게 다시 맞춰짐 (Priority: P3)

사용자는 창 크기나 표시 영역이 달라져도 Mermaid 차트가 현재 공간에 맞춰 보기 좋은 크기로 유지되기를 원한다.

**Why this priority**: 데스크톱 앱 사용 중 창 크기 조절, 패널 크기 변화, 다양한 화면 크기에서 차트 가독성을 유지하는 데 필요하다.

**Independent Test**: 차트가 표시된 상태에서 창 또는 표시 영역 크기를 변경하고, 차트가 새 영역에 맞춰 다시 표시되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** Mermaid 차트가 표시되어 있음, **When** 사용자가 표시 영역의 크기를 변경함, **Then** 차트는 새 표시 영역 안에 맞도록 자동 조정된다.
2. **Given** 표시 영역이 이전보다 작아짐, **When** 차트가 다시 맞춰짐, **Then** 차트는 잘리지 않고 전체 구조를 유지한다.

### Edge Cases

- Mermaid 차트가 매우 넓거나 매우 높은 경우에도 전체 차트가 표시 영역 안에 들어와야 한다.
- 차트 내용이 복잡해 자동 축소 후 텍스트 가독성이 낮아질 수 있는 경우에도, 차트는 표시 영역을 벗어나지 않아야 한다.
- 표시 영역의 크기를 계산할 수 없는 순간에는 기존 표시를 깨뜨리지 않고 안정적인 기본 크기로 표시되어야 한다.
- 차트 렌더링이 완료되기 전에는 잘못된 크기 계산으로 차트가 사라지거나 0 크기로 표시되지 않아야 한다.
- 빈 차트, 잘못된 차트 문법, 렌더링 실패 상태는 기존 오류 표시 흐름을 유지해야 한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 Mermaid 차트를 표시할 때 현재 표시 영역의 사용 가능한 크기에 맞춰 차트 전체가 보이도록 자동 크기 조정을 수행해야 한다.
- **FR-002**: 시스템은 Mermaid 차트의 원본 비율을 유지한 상태로 크기를 조정해야 한다.
- **FR-003**: 시스템은 차트가 현재 표시 영역보다 큰 경우 표시 영역 안에 들어오도록 축소해야 한다.
- **FR-004**: 시스템은 차트가 현재 표시 영역보다 작은 경우에도 사용자가 읽기 어려울 정도로 불필요하게 축소하지 않아야 한다.
- **FR-005**: 시스템은 기존 차트 표시 위치와 진입 흐름을 유지해야 하며, 이 개선만으로 새로운 전체 화면 모달이나 별도 화면 전환을 도입하지 않아야 한다.
- **FR-006**: 시스템은 차트 표시 영역의 크기가 변경되면 현재 영역에 맞는 크기로 차트를 다시 조정해야 한다.
- **FR-007**: 시스템은 차트 렌더링 완료 후 실제 차트 크기를 기준으로 적정 표시 크기를 결정해야 한다.
- **FR-008**: 시스템은 자동 크기 조정 중에도 차트가 사라지거나 표시 영역 밖으로 완전히 밀려나는 상태를 만들지 않아야 한다.
- **FR-009**: 시스템은 차트 렌더링 실패, 빈 내용, 잘못된 Mermaid 문법에 대한 기존 사용자 안내 방식을 유지해야 한다.
- **FR-010**: 시스템은 AW 프로젝트에서 확인된 zoom-to-fit 표시 경험을 참고해 동일한 사용자 기대를 현재 표시 방식 안에서 충족해야 한다.

### Key Entities

- **Mermaid Chart**: 화면에 표시되는 다이어그램 콘텐츠. 차트 문법, 렌더링된 크기, 원본 비율, 표시 가능 여부를 가진다.
- **Display Area**: 차트가 표시되는 현재 화면 영역. 사용 가능한 폭과 높이, 영역 변경 상태를 가진다.
- **Fit Result**: 차트를 표시 영역에 맞추기 위해 결정된 표시 크기와 배율 상태를 나타낸다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 대표 Mermaid 차트 샘플의 95% 이상이 최초 표시 시 현재 표시 영역 안에서 잘리지 않고 전체가 보인다.
- **SC-002**: 큰 차트 샘플은 최초 표시 후 1초 이내에 전체 구조가 보이는 크기로 안정화된다.
- **SC-003**: 사용자는 기존 차트 표시 진입 방식 그대로 차트를 확인할 수 있으며, 개선으로 인해 추가 화면 이동이나 모달 전환이 발생하지 않는다.
- **SC-004**: 표시 영역 크기 변경 후 1초 이내에 차트가 새 영역에 맞게 다시 조정된다.
- **SC-005**: 검증 참여자의 90% 이상이 개선 후 Mermaid 차트가 이전보다 한눈에 파악하기 쉽다고 평가한다.

## Assumptions

- 대상 사용자는 기존 Mermaid 차트 표시 기능을 사용하는 사용자이다.
- 이 기능은 차트의 표시 크기와 맞춤 동작을 개선하는 범위로 한정되며, 차트 편집 기능이나 문법 검증 방식은 변경하지 않는다.
- 현재 표시 방식은 유지되며, 전체 화면 모달 전환은 이번 범위에 포함하지 않는다.
- AW 프로젝트의 zoom-to-fit 동작은 사용자가 기대하는 참고 경험으로 활용되지만, 현재 제품의 화면 구조 안에서 동일한 표시 품질을 제공하는 것이 목표이다.
- 기존 오류 처리와 안내 흐름은 유지된다.
