# Feature Specification: Terminal Inline Render

**Feature Branch**: `002-terminal-inline-render`  
**Created**: 2026-09-10  
**Status**: Draft  
**Input**: User description: "kitty graphics protocol 이용하여, 터미널에 선택한 텍스트가 mermaid 문법일 경우 터미널에 render 된 mermaid 차트를 표시하는 기능을 구현하려고 합니다"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 터미널에서 선택한 차트를 그 자리에서 확인 (Priority: P1)

터미널에서 작업하던 사용자가 화면에 있는 Mermaid 차트 텍스트를 선택하고, 창을 옮기거나 다른 앱으로 전환하지 않고 그 터미널 안에서 렌더된 차트를 바로 확인하기를 원한다.

**Why this priority**: 이 기능의 핵심 가치다. 기존에는 차트를 보려면 데스크톱 창으로 전환해야 했고, 터미널 작업 흐름이 끊겼다.

**Independent Test**: 터미널에 Mermaid 차트 텍스트를 출력해 두고, 그 텍스트를 선택한 뒤 단축키를 누른다. 같은 터미널 화면 안에 차트 이미지가 나타나고 차트 전체가 잘리지 않고 보이는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 터미널 화면에 Mermaid 차트 텍스트가 표시되어 있음, **When** 사용자가 그 텍스트를 선택하고 단축키를 누름, **Then** 같은 터미널 화면에 렌더된 차트 이미지가 인라인으로 표시된다.
2. **Given** 선택한 차트가 터미널 표시 영역보다 큼, **When** 차트가 표시됨, **Then** 차트 전체가 표시 영역 안에 들어오도록 원본 비율을 유지한 채 축소되어 표시된다.
3. **Given** 선택한 텍스트가 ` ```mermaid ` 펜스 코드 블록 안에 있음, **When** 사용자가 블록을 포함해 선택하고 단축키를 누름, **Then** 펜스 표시를 제외한 차트 본문만 렌더되어 표시된다.
4. **Given** 차트가 표시된 직후, **When** 사용자가 계속 명령을 입력함, **Then** 셸 프롬프트는 정상 상태로 남아 있고 입력이 깨지지 않는다.

---

### User Story 2 - Mermaid가 아닌 선택은 작업을 방해하지 않음 (Priority: P2)

사용자는 터미널에서 로그, 코드, 일반 문장 등 온갖 텍스트를 선택한다. 차트가 아닌 텍스트에 대해 단축키가 눌렸을 때 오류 메시지나 불필요한 출력으로 화면이 어지러워지지 않기를 원한다.

**Why this priority**: 오탐과 잡음은 이 기능을 끄게 만드는 가장 큰 이유다. 조용한 실패가 기능 채택의 전제다.

**Independent Test**: Mermaid 키워드가 문장 안에 포함된 일반 텍스트("this text mentions graph but is not a diagram")와 TypeScript 코드 블록을 각각 선택하고 단축키를 누른다. 아무 출력이 없어야 한다.

**Acceptance Scenarios**:

1. **Given** 선택한 텍스트가 Mermaid 차트가 아님, **When** 사용자가 단축키를 누름, **Then** 아무 이미지도 표시되지 않고 오류 메시지도 출력되지 않는다.
2. **Given** 선택 영역이 비어 있음, **When** 사용자가 단축키를 누름, **Then** 아무 일도 일어나지 않는다.
3. **Given** 선택한 텍스트가 Mermaid 선언으로 시작하지만 문법이 잘못됨, **When** 렌더링이 실패함, **Then** 실패 사유가 한 줄로 간결하게 안내된다.

---

### User Story 3 - 사용하는 터미널이 달라도 같은 동작 (Priority: P3)

사용자는 Ghostty를 주로 쓰지만 상황에 따라 WezTerm이나 kitty도 사용한다. 어느 터미널에서든 같은 절차로 같은 결과를 얻기를 원한다.

**Why this priority**: 특정 터미널에만 동작하면 습관으로 굳지 못한다. 다만 세 터미널 모두에서 동작하는 것은 P1 가치가 확보된 다음의 확장이다.

**Independent Test**: Ghostty, WezTerm, kitty에서 각각 같은 차트 텍스트를 선택하고 같은 단축키를 눌러 동일한 차트가 표시되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 사용자가 Ghostty·WezTerm·kitty 중 하나를 사용 중, **When** 차트 텍스트를 선택하고 단축키를 누름, **Then** 세 터미널에서 모두 차트가 인라인으로 표시된다.
2. **Given** 사용 중인 터미널이 이미지 표시를 지원하지 않음, **When** 사용자가 단축키를 누름, **Then** 이미지를 표시할 수 없다는 사실과 이유를 한 줄로 알린다.
3. **Given** 터미널마다 필요한 사전 설정이 다름, **When** 사용자가 설치 안내를 확인함, **Then** 사용 중인 터미널에 필요한 설정만 명확히 제시된다.

---

### User Story 4 - 복사만으로 차트가 보임 (Priority: P2)

사용자는 다른 창에서 Mermaid 차트를 복사해 올 때가 많다. 그럴 때는 터미널에서 다시 선택하고 단축키를 누르는 대신, 복사하는 순간 터미널에 차트가 나타나기를 원한다.

**Why this priority**: 선택 후 단축키(P1)가 없으면 이 기능도 의미가 없으므로 그 다음이다. 다만 외부에서 차트를 받아 오는 흐름에서는 선택 단계 자체가 불필요해 마찰이 더 크게 줄어든다.

**Independent Test**: 감시 모드를 실행해 두고 다른 애플리케이션에서 Mermaid 차트를 복사한다. 터미널에 차트가 나타나는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 사용자가 감시 모드를 실행해 둠, **When** 어디서든 Mermaid 차트를 클립보드에 복사함, **Then** 그 터미널에 렌더된 차트가 나타난다.
2. **Given** 감시 모드가 실행 중, **When** 차트가 아닌 텍스트를 복사함, **Then** 아무것도 표시되지 않는다.
3. **Given** 방금 표시된 차트와 같은 내용을 다시 복사함, **When** 감시가 이를 확인함, **Then** 같은 차트를 반복해서 표시하지 않는다.
4. **Given** 차트가 감시 모드로 터미널에 표시됨, **When** 사용자가 트레이를 확인함, **Then** 이미 본 차트에 대한 알림이나 배지가 쌓이지 않는다.

---

### Edge Cases

- 이미지 표시를 지원하지 않는 터미널에서 실행되면 이스케이프 문자가 화면에 그대로 쏟아지지 않아야 한다.
- 렌더링을 담당하는 데스크톱 앱이 실행되지 않은 상태에서도 사용자가 무엇을 해야 하는지 알 수 있어야 한다.
- 매우 큰 텍스트를 선택한 경우 차트 판별과 렌더링에 과도한 비용을 쓰지 않아야 한다.
- 차트가 세로로 매우 긴 경우 화면 높이를 넘겨 프롬프트를 밀어내지 않아야 한다.
- 터미널 창이 매우 좁은 경우에도 표시가 깨지지 않아야 한다.
- 같은 차트를 연속으로 요청할 때 매번 처음부터 렌더링하지 않아야 한다.
- 터미널에서 차트를 선택하는 동작이 기존 클립보드 감시의 트레이 알림과 중복되어 같은 차트를 두 번 알리지 않아야 한다.
- 감시 모드 중에 터미널 창 크기가 바뀌면 이후 차트는 새 크기에 맞춰 표시되어야 한다.
- 감시 모드 중에 렌더링 서비스가 멈추거나 재시작되면, 사용자가 다시 실행하지 않아도 복구되어야 한다.
- 감시가 꺼져 있어 아무것도 도착하지 않는 상태와, 감시는 켜져 있으나 아직 복사한 차트가 없는 상태를 사용자가 구분할 수 있어야 한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 사용자가 터미널에서 선택한 텍스트를 단축키 한 번으로 차트 표시 요청으로 전달할 수 있어야 한다.
- **FR-002**: 시스템은 선택한 텍스트가 Mermaid 차트인지 판별해야 하며, 판별 기준은 기존 클립보드 감지와 동일해야 한다. 여기에는 펜스 코드 블록 추출과 frontmatter·directive·주석 전처리가 포함된다.
- **FR-003**: 시스템은 판별된 Mermaid 차트를 이미지로 렌더링해 터미널 화면 안에 인라인으로 표시해야 한다.
- **FR-004**: 시스템은 차트 전체가 현재 터미널 표시 영역 안에 들어오도록 크기를 조정하되 원본 비율을 유지해야 한다.
- **FR-005**: 시스템은 선택한 텍스트가 Mermaid 차트가 아니거나 비어 있으면 아무 출력 없이 종료해야 한다.
- **FR-006**: 시스템은 이미지 표시를 지원하지 않는 터미널에서 실행될 경우 이를 감지해 안내 후 안전하게 종료해야 하며, 표시용 제어 문자를 출력하지 않아야 한다.
- **FR-007**: 시스템은 차트 문법 오류 등으로 렌더링이 실패하면 실패 사유를 한 줄로 안내해야 한다.
- **FR-008**: 시스템은 차트를 표시한 뒤 셸 프롬프트와 입력 중인 명령줄을 정상 상태로 유지해야 한다.
- **FR-009**: 시스템은 동일한 차트를 같은 크기로 다시 요청할 때 첫 요청보다 빠르게 표시해야 한다.
- **FR-010**: 시스템은 터미널에 표시되는 차트가 데스크톱 미리보기와 같은 테마 색상 정의를 사용하도록 해야 한다.
- **FR-011**: 시스템은 터미널을 통해 표시한 차트에 대해 기존 트레이 알림이 중복 발생하지 않도록 해야 한다.
- **FR-012**: 시스템은 렌더링 서비스가 준비되지 않은 경우 사용자가 취할 조치를 안내해야 한다.
- **FR-013**: 시스템은 사용자가 자신의 터미널 환경에서 기능이 동작할 준비가 되었는지 스스로 확인할 수 있는 진단 수단을 제공해야 한다.
- **FR-014**: 시스템은 클립보드에 새 Mermaid 차트가 들어올 때마다 사용자가 별도 조작 없이 터미널에서 그 차트를 볼 수 있는 지속 모드를 제공해야 한다.
- **FR-015**: 시스템은 지속 모드에서 차트가 아닌 클립보드 변경에는 아무것도 표시하지 않아야 한다.
- **FR-016**: 시스템은 지속 모드에서 이미 표시한 차트를 다시 표시하지 않아야 한다.
- **FR-017**: 시스템은 지속 모드로 표시한 차트에 대해 기존 트레이 알림과 배지가 발생하지 않도록 해야 한다.
- **FR-018**: 시스템은 지속 모드에서 감시가 준비되었는지, 그리고 감시가 꺼져 있어 아무것도 오지 않는 상태인지를 사용자에게 알려야 한다.
- **FR-019**: 시스템은 지속 모드에서 터미널 크기가 바뀌면 이후 차트를 새 크기에 맞춰 표시해야 하고, 렌더링 서비스와의 연결이 끊기면 스스로 복구해야 한다.

### Key Entities

- **Selected Text**: 사용자가 터미널에서 선택한 원본 텍스트. 차트일 수도 있고 아닐 수도 있다.
- **Chart Render Request**: 차트 원문과 목표 표시 크기를 담은 렌더링 요청.
- **Rendered Chart Image**: 렌더링 결과 이미지와 그 원본 픽셀 크기.
- **Terminal Capability**: 사용 중인 터미널의 이미지 표시 지원 여부와 셀 크기 정보.
- **Display Area**: 차트가 표시될 터미널의 사용 가능한 칸 격자 영역.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사용자는 텍스트 선택 후 단축키 한 번으로 차트를 확인할 수 있으며, 추가 명령 입력이나 앱 전환이 필요하지 않다.
- **SC-002**: 첫 차트 표시는 3초 이내, 같은 차트의 재표시는 1초 이내에 완료된다.
- **SC-003**: 대표 차트 샘플의 95% 이상이 잘리지 않고 터미널 표시 영역 안에 전체가 보인다.
- **SC-004**: Mermaid가 아닌 텍스트를 선택해 단축키를 눌렀을 때 발생하는 출력은 0건이다.
- **SC-005**: Ghostty, WezTerm, kitty 세 터미널에서 동일한 선택·단축키 절차로 차트가 표시된다.
- **SC-006**: 차트 표시 후 셸 프롬프트가 깨지거나 입력 중이던 명령줄이 사라지는 사례가 0건이다.
- **SC-007**: 지속 모드에서 차트를 복사한 뒤 5초 이내에 터미널에 차트가 나타난다.
- **SC-008**: 지속 모드에서 차트가 아닌 텍스트를 복사했을 때 발생하는 출력은 0건이고, 같은 차트를 다시 복사했을 때 중복 표시도 0건이다.

## Assumptions

- 대상 환경은 macOS이며 셸은 zsh이다.
- 렌더링은 이미 설치된 데스크톱 앱이 담당한다. 별도의 브라우저 엔진을 새로 도입하지 않는다.
- 사용자는 터미널에서 텍스트를 선택하면 클립보드에 반영되는 설정을 사용한다. 기본값이 그렇지 않은 터미널은 설치 안내에서 필요한 설정을 제시한다.
- 이미지 인라인 표시는 kitty graphics protocol을 지원하는 터미널에서만 제공한다.
- 차트 판별 기준은 기존 클립보드 감지 로직을 단일 기준으로 재사용하며, 이번 기능에서 판별 규칙 자체를 바꾸지 않는다.
- 이 기능은 표시 경로를 추가하는 범위이며, 기존 클립보드 감시와 트레이 흐름을 대체하지 않는다.
