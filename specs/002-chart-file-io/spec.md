# 기능 명세: Mermaid 차트 파일 열기 및 저장

**기능 브랜치**: `002-chart-file-io`  
**작성일**: 2026-08-01  
**상태**: 초안  
**입력**: 사용자 설명: "Mermaid chart 문서를 파일로 저장하고 읽는 기능을 추가합니다"

## 사용자 시나리오 및 테스트 *(필수)*

### 사용자 스토리 1 - 차트 문서를 파일로 저장 (우선순위: P1)

사용자는 편집 중인 단일 Mermaid 차트를 로컬 파일로 저장하고, 이후 변경사항을 같은 파일에 빠르게 반영할 수 있다.

**우선순위 근거**: 편집 결과를 보존하고 다시 사용할 수 있게 하는 핵심 가치이며, 파일 기반 작업 흐름의 출발점이다.

**독립 테스트**: 새 문서를 저장하고 내용을 수정한 다음 다시 저장하여, 선택한 파일에 최신 내용이 유지되는지 확인할 수 있다.

**인수 시나리오**:

1. **Given** 저장 경로가 없는 새 차트를 편집 중임, **When** 사용자가 저장을 선택함, **Then** 저장 위치와 파일명을 선택할 수 있고 선택한 경로에 차트 내용이 저장된다.
2. **Given** 차트가 기존 파일과 연결되어 있음, **When** 사용자가 내용을 수정하고 저장함, **Then** 추가 경로 선택 없이 연결된 파일이 최신 내용으로 갱신된다.
3. **Given** 사용자가 다른 이름으로 저장을 선택함, **When** 새 경로와 지원되는 파일명을 확정함, **Then** 현재 차트 내용이 새 파일에 저장되고 편집 문서는 새 파일과 연결된다.
4. **Given** 사용자가 확장자 없이 새 파일명을 입력함, **When** 저장을 확정함, **Then** 기본 `.mmd` 확장자가 자동으로 적용된다.

---

### 사용자 스토리 2 - 기존 차트 파일 열기 (우선순위: P1)

사용자는 로컬에 저장된 `.mmd` 또는 `.mermaid` 파일을 선택해 현재 활성 편집기에서 열고 편집을 계속할 수 있다.

**우선순위 근거**: 저장된 작업을 다시 불러올 수 있어야 파일 저장 기능이 완전한 문서 작업 흐름을 제공한다.

**독립 테스트**: 지원되는 파일을 열어 원본 내용이 편집기에 표시되고, 수정 후 같은 파일에 저장되는지 확인할 수 있다.

**인수 시나리오**:

1. **Given** 현재 활성 편집기가 있음, **When** 사용자가 열기 기능으로 `.mmd` 또는 `.mermaid` 파일을 선택함, **Then** 선택한 파일의 전체 내용이 현재 편집 문서를 대체한다.
2. **Given** 지원되는 파일을 열었음, **When** 사용자가 내용을 수정하고 저장함, **Then** 수정 내용이 열린 원본 파일에 반영된다.
3. **Given** Mermaid 문법 오류가 있는 지원 파일을 선택함, **When** 파일을 열음, **Then** 원문은 편집기에 표시되고 사용자는 기존 오류 안내를 보며 문법을 수정할 수 있다.
4. **Given** 파일 선택창이 열려 있음, **When** 사용자가 파일 목록을 확인함, **Then** 지원되는 Mermaid 원문 파일 형식을 식별하고 선택할 수 있다.

---

### 사용자 스토리 3 - 저장하지 않은 변경 보호 (우선순위: P2)

사용자는 변경사항을 저장하지 않은 채 문서를 닫거나 다른 파일을 열려고 할 때 작업 손실을 방지할 수 있다.

**우선순위 근거**: 명시적인 확인 없이 편집 내용을 잃는 문제는 파일 작업에 대한 신뢰를 크게 훼손한다.

**독립 테스트**: 문서를 수정한 뒤 닫기 또는 다른 파일 열기를 시도하고, 저장·저장 안 함·취소의 각 선택이 예상대로 동작하는지 확인할 수 있다.

**인수 시나리오**:

1. **Given** 현재 문서에 저장되지 않은 변경이 있음, **When** 사용자가 문서를 닫거나 다른 파일을 열려고 함, **Then** 저장, 저장 안 함, 취소를 선택할 수 있는 손실 방지 확인이 표시된다.
2. **Given** 손실 방지 확인이 표시됨, **When** 사용자가 저장을 선택함, **Then** 변경사항이 저장된 후 원래 요청한 닫기 또는 열기 작업이 계속된다.
3. **Given** 손실 방지 확인이 표시됨, **When** 사용자가 저장 안 함을 선택함, **Then** 변경사항을 버리고 원래 요청한 작업이 계속된다.
4. **Given** 손실 방지 확인이 표시됨, **When** 사용자가 취소를 선택함, **Then** 원래 요청한 작업이 중단되고 현재 문서와 편집 내용이 유지된다.
5. **Given** 현재 문서에 저장되지 않은 변경이 없음, **When** 사용자가 문서를 닫거나 다른 파일을 열려고 함, **Then** 추가 확인 없이 요청한 작업이 진행된다.

---

### 사용자 스토리 4 - 외부 파일 변경 충돌 보호 (우선순위: P2)

사용자는 열린 파일이 다른 프로그램에서 변경된 경우 자신의 편집 내용 또는 외부 변경을 실수로 덮어쓰지 않고 처리 방법을 선택할 수 있다.

**우선순위 근거**: 외부 편집기나 동기화 도구와 함께 사용할 때 발생할 수 있는 조용한 데이터 손실을 방지한다.

**독립 테스트**: 앱에서 파일을 연 뒤 외부에서 같은 파일을 변경하고 저장을 시도하여, 다시 불러오기·덮어쓰기·취소 선택이 각각 올바르게 적용되는지 확인할 수 있다.

**인수 시나리오**:

1. **Given** 열린 파일이 마지막으로 불러온 이후 외부에서 변경됨, **When** 사용자가 저장을 시도함, **Then** 디스크 내용 다시 불러오기, 현재 내용으로 덮어쓰기, 취소를 선택할 수 있는 충돌 확인이 표시된다.
2. **Given** 충돌 확인이 표시됨, **When** 사용자가 디스크 내용 다시 불러오기를 선택함, **Then** 외부 변경 내용이 편집기에 표시되고 앱의 미저장 변경은 버려진다.
3. **Given** 충돌 확인이 표시됨, **When** 사용자가 현재 내용으로 덮어쓰기를 선택함, **Then** 현재 편집 내용이 해당 파일에 저장된다.
4. **Given** 충돌 확인이 표시됨, **When** 사용자가 취소를 선택함, **Then** 파일과 현재 편집 내용 모두 변경되지 않는다.

---

### 사용자 스토리 5 - 현재 문서 상태 식별 (우선순위: P3)

사용자는 현재 편집 중인 파일과 저장되지 않은 변경의 존재 여부를 창 제목에서 즉시 확인할 수 있다.

**우선순위 근거**: 여러 창이나 탭을 사용할 때 잘못된 문서를 편집하거나 저장하는 실수를 줄인다.

**독립 테스트**: 새 문서, 저장된 문서, 수정된 문서 상태를 차례로 만들고 창 제목의 파일명과 변경 표시가 상태에 맞게 바뀌는지 확인할 수 있다.

**인수 시나리오**:

1. **Given** 아직 저장하지 않은 새 문서를 편집 중임, **When** 창 제목을 확인함, **Then** 제목 없음 상태와 앱 이름을 식별할 수 있다.
2. **Given** 파일을 열거나 저장하여 문서가 파일과 연결됨, **When** 창 제목을 확인함, **Then** 현재 파일명과 앱 이름을 식별할 수 있다.
3. **Given** 저장된 문서 내용을 변경함, **When** 창 제목을 확인함, **Then** 저장되지 않은 변경이 있음을 나타내는 명확한 표시가 보인다.
4. **Given** 변경사항 저장이 완료됨, **When** 창 제목을 확인함, **Then** 저장되지 않은 변경 표시가 제거된다.

### 예외 상황

- 사용자가 파일 열기, 최초 저장 또는 다른 이름으로 저장 창을 취소하면 현재 문서와 파일은 변경되지 않아야 한다.
- 존재하지 않거나 접근 권한이 없거나 읽을 수 없는 파일은 현재 문서를 교체하지 않고 오류를 안내해야 한다.
- 저장 경로에 쓸 수 없거나 저장 도중 실패하면 기존 파일과 현재 편집 내용을 가능한 한 보존하고 오류를 안내해야 한다.
- 빈 `.mmd` 또는 `.mermaid` 파일은 열 수 있으며, 빈 편집 상태와 기존 미리보기 안내를 유지해야 한다.
- 잘못된 Mermaid 문법은 파일 열기를 차단하지 않아야 한다.
- `.mmd`, `.mermaid` 이외의 확장자는 열기 및 새 파일 저장 대상으로 허용하지 않아야 한다.
- 외부 변경을 다시 불러오려는 시점에 파일이 삭제되거나 읽을 수 없게 된 경우 현재 편집 내용을 유지하고 오류를 안내해야 한다.
- 손실 방지 확인에서 저장을 선택했지만 저장이 실패하거나 취소되면 닫기 또는 파일 교체 작업도 중단되어야 한다.

## 요구사항 *(필수)*

### 기능 요구사항

- **FR-001**: 시스템은 사용자가 현재 활성 편집기에서 로컬 Mermaid 원문 파일을 선택해 열 수 있도록 해야 한다.
- **FR-002**: 시스템은 열기 대상으로 `.mmd`와 `.mermaid` 확장자의 단일 차트 문서만 지원해야 한다.
- **FR-003**: 시스템은 열기 기능을 메뉴에서 제공하고 `Cmd/Ctrl+O` 단축키로 실행할 수 있도록 해야 한다.
- **FR-004**: 시스템은 선택한 파일의 전체 원문을 현재 활성 편집 문서로 불러와야 한다.
- **FR-005**: 시스템은 Mermaid 문법 오류가 있는 지원 파일도 열어 사용자가 내용을 수정할 수 있도록 해야 한다.
- **FR-006**: 시스템은 새 문서의 최초 저장 시 저장 위치와 파일명을 선택하도록 해야 한다.
- **FR-007**: 시스템은 파일과 연결된 문서의 저장 요청 시 추가 경로 선택 없이 같은 파일을 갱신해야 한다.
- **FR-008**: 시스템은 사용자가 현재 문서를 새 경로에 저장하고 그 경로를 현재 문서와 연결하는 다른 이름으로 저장 기능을 제공해야 한다.
- **FR-009**: 시스템은 저장 기능을 메뉴에서 제공하고 `Cmd/Ctrl+S` 단축키로 실행할 수 있도록 해야 한다.
- **FR-010**: 시스템은 새 파일명에 확장자가 없으면 `.mmd`를 자동으로 추가해야 한다.
- **FR-011**: 시스템은 기존 `.mmd` 또는 `.mermaid` 문서를 저장할 때 원래 확장자를 유지해야 한다.
- **FR-012**: 시스템은 지원되지 않는 확장자로 새 파일을 저장하지 못하게 하고 지원 형식을 안내해야 한다.
- **FR-013**: 시스템은 현재 문서의 원문이 마지막 저장 또는 불러오기 상태와 다른지 추적해야 한다.
- **FR-014**: 시스템은 저장하지 않은 변경이 있는 상태에서 문서 닫기 또는 다른 파일 열기를 요청하면 저장, 저장 안 함, 취소 선택을 제공해야 한다.
- **FR-015**: 시스템은 손실 방지 확인에서 선택한 결과에 따라 저장 후 계속, 변경 폐기 후 계속, 작업 취소 중 하나를 정확히 수행해야 한다.
- **FR-016**: 시스템은 손실 방지 과정의 저장이 완료되지 않으면 문서 닫기 또는 파일 교체를 진행하지 않아야 한다.
- **FR-017**: 시스템은 열린 파일이 마지막 불러오기 또는 저장 이후 외부에서 변경되었는지 저장 전에 확인해야 한다.
- **FR-018**: 시스템은 외부 변경 충돌이 있으면 디스크 내용 다시 불러오기, 현재 내용으로 덮어쓰기, 취소 선택을 제공해야 한다.
- **FR-019**: 시스템은 파일 읽기 또는 저장 실패 시 현재 편집 내용을 보존하고 사용자가 이해할 수 있는 오류를 표시해야 한다.
- **FR-020**: 시스템은 창 제목에 제목 없음 또는 현재 파일명과 앱 이름을 표시해야 한다.
- **FR-021**: 시스템은 저장되지 않은 변경의 유무를 창 제목에 명확하게 표시하고 저장 완료 후 해당 표시를 제거해야 한다.
- **FR-022**: 시스템은 파일 선택이나 확인 창을 사용자가 취소했을 때 현재 문서, 파일 연결, 저장 상태를 변경하지 않아야 한다.

### 핵심 개체

- **차트 문서**: 하나의 Mermaid 차트 원문과 현재 편집 내용, 마지막 저장 또는 불러오기 내용, 저장되지 않은 변경 여부를 나타낸다.
- **문서 파일 연결**: 차트 문서와 로컬 `.mmd` 또는 `.mermaid` 파일 사이의 연결로, 경로, 파일명, 지원 형식 및 마지막으로 확인한 외부 상태를 포함한다.
- **문서 작업 요청**: 열기, 저장, 다른 이름으로 저장, 닫기처럼 현재 문서나 연결 파일의 상태를 바꾸려는 사용자 작업을 나타낸다.
- **충돌 결정**: 외부 변경이 발견되었을 때 디스크 내용 다시 불러오기, 현재 내용으로 덮어쓰기, 취소 중 사용자가 선택한 처리 결과를 나타낸다.

## 성공 기준 *(필수)*

### 측정 가능한 결과

- **SC-001**: 사용자는 지원되는 기존 차트 파일을 선택한 뒤 3초 이내에 편집 가능한 상태로 내용을 확인할 수 있다.
- **SC-002**: 사용자는 새 차트를 저장하거나 열린 차트의 변경사항을 저장하는 기본 작업을 3단계 이내에 완료할 수 있다.
- **SC-003**: 정상적인 읽기·쓰기 환경에서 100개의 대표 `.mmd` 및 `.mermaid` 파일을 열고 저장했을 때 원문 내용 보존 성공률이 100%이다.
- **SC-004**: 미저장 변경이 있는 닫기 및 파일 교체 시나리오에서 사용자 확인 없이 편집 내용이 손실되는 경우가 0건이다.
- **SC-005**: 외부 변경 충돌 시나리오에서 사용자 선택 없이 디스크 파일 또는 현재 편집 내용이 덮어써지는 경우가 0건이다.
- **SC-006**: 파일 열기, 저장, 다른 이름으로 저장, 취소 또는 실패 후 창 제목의 파일명과 변경 상태가 실제 문서 상태와 일치하는 비율이 100%이다.
- **SC-007**: 검증 참여자의 90% 이상이 메뉴와 표준 단축키를 사용해 별도 안내 없이 파일 열기와 저장을 완료할 수 있다.

## 가정

- 대상 사용자는 자신의 로컬 파일에 접근할 수 있는 단일 사용자이며 별도 계정이나 권한 역할은 필요하지 않다.
- 파일 내용은 하나의 Mermaid 차트를 표현하는 원문이며 Markdown 문서와 여러 차트가 포함된 문서는 이번 범위에서 제외한다.
- 지원 파일 형식은 `.mmd`와 `.mermaid`로 제한하고 새 문서의 기본 확장자는 `.mmd`로 한다.
- 열기 작업은 현재 활성 편집기의 문서를 교체하며 새 창이나 새 탭을 자동으로 만들지 않는다.
- 여러 문서를 동시에 편집하려는 사용자는 기존 새 창 또는 새 탭 기능을 사용할 수 있다.
- 자동 저장, 비정상 종료 복구본, 최근 파일 목록, 드래그 앤 드롭, 운영체제 파일 연결은 이번 범위에서 제외한다.
- 파일 내용의 유효성 안내와 미리보기 오류 표시는 기존 편집 경험을 유지한다.
- 사용자에게 표시하는 파일명은 전체 경로 대신 문서를 식별하기 쉬운 기본 파일명을 사용한다.
